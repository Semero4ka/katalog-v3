КАТАЛОГ ОПТОВЫХ ЦЕН — PWA-приложение (версия 3)

СОСТАВ:
  index.html          — приложение (каталог + корзина + заявки)
  data.js             — данные прайса (цены обновлять только здесь)
  sw.js               — сервис-воркер (офлайн-кэш)
  service-worker.js   — копия сервис-воркера
  manifest.webmanifest— настройки PWA
  icon-192.png, icon-512.png — иконки приложения
  README.txt          — эта инструкция

УСТАНОВКА НА GITHUB PAGES:
1. Создайте репозиторий (Public).
2. Add file -> Upload files и загрузите ВСЕ файлы из этой папки
   (включая папку img, если есть) прямо в корень репозитория.
3. Settings -> Pages -> Branch: main, папка: / (root) -> Save.
4. Через 1–2 минуты сайт откроется по адресу
   https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/

Если сайт уже был опубликован: замените файлы через Add file ->
Upload files (одинаковые имена перезапишутся) и обязательно
поднимите версию кэша в sw.js: catalog-v3 -> catalog-v4.

ВОЗМОЖНОСТИ:
- Поиск по названию и цене, фильтр по категориям, сортировка.
- Кнопка «+ В корзину» у каждого товара, количество — кнопками −/+.
- Корзина: итоговая сумма, изменение количества, удаление.
- Оформление заявки: имя, телефон (проверка), комментарий.
- Заявка сохраняется в «Мои заявки»; кнопка «Скопировать» готовит
  текст для отправки менеджеру (WhatsApp/Telegram/SMS).
- Корзина и заявки хранятся локально в браузере устройства.
- Полностью работает офлайн после установки.

ФОТО ТОВАРОВ (опционально):
Положите в папку img файлы 1.jpg, 2.jpg и т.д. — номер соответствует
позиции товара в data.js (счёт с начала файла). Пока фото нет,
показывается заглушка.

Обновление прайса: замените только data.js — версия кэша при этом
менять не нужна, если остальные файлы не менялись.
